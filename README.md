# Fra-JSON-til-API

## Hva er JSON?
En fil som koden kan ta informasjon fra, som er bra for å ha mer ryddig kode for eksempel hvis du må ha mye informasjon.
<br><br>

## Hvordan er JSON bygget opp?
.json er en fil som består av lister, objekter og nøkkeler som er satt systematisk.
<br><br>

## Hva var lett?
Jeg synes det var enkelt å bruke lister og objekter i .json filer. Jeg synes også hvordan man henter informasjonen fra .json var relativt enkelt.
<br><br>

## Hva var vanskelig?
Jeg slet med API på oppgave 6, men jeg fikk hjelp av Emil Andrä.
<br><br>

## Hva er forskjellen mellom en lokal JSON-fil og et API?
- .json er en fil på pc'en din, som koden kna hente informasjon fra.
- API er noe som ligger på nettet, som koden kan hente informasjon fra via en for eksempel en API-key.
